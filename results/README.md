# Сохранённый эксперимент

`run.json` содержит настройки, версии библиотек, границы выборок и SHA-256 исходных CSV.
`metrics.csv` содержит метрики каждого запуска; seed=-1 означает детерминированную модель.
`summary.csv` содержит средние метрики и стандартное отклонение RMSE по seed (ddof=0).

В `*_predictions.csv` находятся факты и прогнозы моделей на общих датах; нейросети показаны
для seed=42. В `*_all_seeds.csv` сохранены все три запуска нейросетей.
`*_loss.json` и `*_loss.png` относятся к подбору числа эпох для seed=42.

`*_series.png` показывает исходный ряд, `*_test.png` — весь тест,
`*_drop.png` — наблюдения с 3 апреля 2025 UTC до конца файла.
Численные результаты и их ограничения разобраны в [отчёте](../REPORT.md).
