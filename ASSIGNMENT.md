# Соответствие исходному семинару

Источник задания: предоставленный блокнот `MosPolytechSeminarNN_(Игнатенко М.В.)_.ipynb`.
Его сохранённые выводы не используются как результаты нового эксперимента.

| Пункт шаблона | Реализация |
| --- | --- |
| Загрузка и нормализация | `load_data`, `make_sequences`, `neural_forecast` в `ftse.py` |
| AR на уровнях | `AutoReg`, обновляемые лаги в `ar_forecast` |
| AR на разностях | `ar_forecast(..., differenced=True)`; отдельный вариант `expanding=True` |
| RNN в PyTorch | `RecurrentModel('RNN')`, `nn.RNN`, линейный выход |
| LSTM в PyTorch | `RecurrentModel('LSTM')`, `nn.LSTM`, линейный выход |
| Обучение и графики потерь | `fit_network`, средняя потеря эпохи и validation |
| Скользящий одношаговый прогноз | Каждое окно заканчивается перед своей целевой датой |
| MSE, MAE, RMSE | `metrics`, одинаковые тестовые даты и пункты индекса |
| Сравнение при падении | Период с 3 апреля 2025 UTC, таблицы и графики `*_drop.png` |
| Почему нейросети хуже и как исправить | Раздел 8 блокнота, `REPORT.md`, варианты `_diff` |

Шаблон переработан в самостоятельный блокнот `FTSE_completed.ipynb`, потому что
простое заполнение пропусков оставляло ошибки масштаба, утечку при нормализации
и смещение прогнозов относительно целей. Весь вычислительный код виден в ячейках.
Модуль `ftse.py` содержит те же определения для запуска без Jupyter.

Дополнения к обязательной части: ориентир последней цены, validation, три seed,
полный журнал численных результатов и проверки отсутствия будущих значений в окнах.
