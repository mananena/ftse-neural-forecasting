# FTSE: прогнозирование с AR, RNN и LSTM

[Открыть выполненный блокнот](FTSE_completed.ipynb) · [Открыть в Google Colab](https://colab.research.google.com/github/mananena/ftse-neural-forecasting/blob/main/FTSE_completed.ipynb) · [Отчёт с выводами](REPORT.md)

Решение семинара по временным рядам на PyTorch. Использованы два приложенных CSV: дневные цены FTSE
и четырёхчасовые наблюдения. Реализованы AR на уровнях и разностях, RNN, LSTM, их варианты на разностях
и ориентир последней цены. Исправлены ошибки нормализации, масштаба метрик и совмещения дат из шаблона.

## Результат

| Модель | RMSE дневного теста | RMSE четырёхчасового теста |
| --- | ---: | ---: |
| Naive | 93.69 | 80.74 |
| AR | 98.57 | 79.54 |
| AR_diff | 94.27 | 79.51 |
| AR_diff_expanding | 94.01 | 85.52 |
| RNN | 119.12 | 78.69 |
| LSTM | 117.61 | 105.24 |
| RNN_diff | 93.79 | 81.12 |
| LSTM_diff | 94.39 | 80.17 |

Для нейросетей указано среднее по seed 42, 7, 123. Полные MSE, MAE, RMSE и разброс находятся в отчёте.
Разности заметно помогают дневным нейросетям и четырёхчасовой LSTM, но не улучшают все варианты.
На дневном тесте лучший RMSE у простого ориентира, на четырёхчасовом — у обычной RNN.

Проверяется одно следующее наблюдение с доступом к прошлым фактическим ценам. Это не прогноз всей
траектории заранее. Апрельская оценка содержит только 3 дневные и 10 четырёхчасовых точек.

## Запуск

Самый простой способ — открыть ссылку Colab выше и выполнить все ячейки. Вычислительный код
полностью включён в блокнот; недостающие CSV он скачает из этого репозитория. GPU не требуется.
Сохранённые результаты уже доступны без запуска. Установленные в Colab версии могут отличаться
от зафиксированного локального окружения; фактические версии записываются при каждом запуске.

Для локального запуска рекомендуется Python 3.12:

```bash
git clone https://github.com/mananena/ftse-neural-forecasting.git
cd ftse-neural-forecasting
python -m venv .venv
```

Активация в PowerShell: `.venv\Scripts\Activate.ps1`; Linux/macOS: `source .venv/bin/activate`.

```bash
python -m pip install -r requirements.txt
python ftse.py
python -m unittest discover -s tests -v
```

`python ftse.py` заново обучает модели и перезаписывает файлы `results/`; сохранённые выводы
блокнота обновляются при выполнении самого блокнота. Таблицы и графики в results относятся
к последнему запуску. Для отдельного эксперимента можно указать `python ftse.py --out results_new`.

## Файлы

- `FTSE_completed.ipynb` — выполненный блокнот с кодом, таблицами, графиками и ответом на дополнительный вопрос.
- `ftse.py` — те же вычислительные функции для запуска из командной строки.

- `results/metrics.csv` — метрики каждого запуска; `summary.csv` — средние и разброс.

- `results/*_all_seeds.csv` — прогнозы нейросетей для всех трёх seed.

- `REPORT.md` — разбор результатов и ограничений.
- `ASSIGNMENT.md` — соответствие пунктам исходного семинара.
- `tests/` — проверки окон, причинности прогнозов и метрик.
